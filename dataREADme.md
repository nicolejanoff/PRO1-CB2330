# Where the numbers came from, and their shape
The data used in this project were concentrations and EC50. The numbers come from Table S11 in the excel file "Supplementary Tables", located in "Supplementary Information" in the report. 

The data is organized into 13 columns, 80 rows (29 breast cancer, 40 skin cancer, 11 bone cancer). The columns have the following headers:

CCLE Cell Line Name	Primary Cell | Line Name | Compound	| Target	Doses (uM) |	Activity Data (median) |	Activity | SD |	Num Data |	FitType	| EC50 (µM) |	IC50 (µM) |	Amax |	ActArea
