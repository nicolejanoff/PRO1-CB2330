# PRO1-CB2330
Project repositiory made for the course CB2330 at KTH, made by Esmeralda Edvardsson and Nicole Janoff. 

The aim of the project was to model the drug response using a simplified Hill equation using data från supplementary table S11 from the study Barretina, J. et al. (2012) The Cancer Cell Line Encyclopedia enables predictive modelling of anticancer drug sensitivity. Nature 483:603-607. https://doi.org/10.1038/nature11003. The project used forward simulation to simulate single experiments and and statistical measurements to estimate the accuracy of the chosen model. 

This project introduces a probalistic approach to the original paper by quantifying the uncertainty, and using Bayesian Inference and MC simulations. It also gives a simple illustration of the papers finding by illustrating how the Hill equations differ between different cancer cell lines.

All code necessary to run the simulations is included, so there is no need to import any other data. The data set used is included in the "data/" file.
